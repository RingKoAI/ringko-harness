# v0.7.6

## Updates and security

- Add `ringko update [--check]` and startup version detection. Configure
  `updates.checkOnStartup` (default true) and `updates.autoUpdate` (default false)
  in user settings or an explicit configuration file.
- Update owning global npm installations or official standalone bundles.
  Standalone updates verify SHA-256 and the executable version, replace the
  binary and WebUI together, and roll back failed replacements.
- Upgrade Mermaid's KaTeX renderer to 0.18.10, with a minimum constraint of 0.18.2,
  addressing GHSA-238p-pmpm-9mq7.

## Correctness and reliability

- Isolate new session folders by canonical workspace key and encode session ids
  with device-safe, case-safe, fixed-width escapes. Legacy sessions remain
  discoverable and writable in place; scoped lists verify the header workspace.
- Reject duplicate log creation instead of corrupting an existing session.
- Preserve all matching events across paginated subscription cursors.
- Chunk long timer delays without firing schedules early or shifting deadlines.
- Apply text output limits after the requested line offset so large files remain
  pageable.
- Resolve subagent file tools and shells from the requested working directory,
  retaining parent permissions and approvals. Persist the provider-selected
  default model id so OpenAI children cold-resume correctly.
- Settle each run with a stable id and an explicit completed, failed or cancelled
  event. Preserve primary errors, aggregate cleanup failures and bound shutdown.
- Keep interrupted historical tasks unknown during later runs and correlate job
  cancellation with the delegated task.
- Activate newly added WebUI project directories and load their skills and MCP
  tools, while respecting active-run and pinned-backend boundaries.

## CLI, subagents and WebUI

- Rename `ringko serve` to `ringko web`; backend reuse, shared-workspace mode,
  ports and service commands remain available.
- Add durable named subagent providers for in-process agents, OpenAI Responses
  and Chat Completions, Claude Code, Codex, ACP and generic CLI adapters.
  `task_control` supports inspection, follow-ups, interruption and cold resume.
  OpenAI supports API keys, ChatGPT browser/device OAuth, account selection,
  model allowlists and custom base URLs.
- Require approval for external providers and working directories outside the
  workspace; retain the parent capability gate for in-process children.
- Resolve read, grep and glob targets through filesystem links before permission
  classification and reject changed targets. Searches skip linked entries.
  Deny/ask rules match lexical and resolved targets; allow rules match only the
  resolved target.
- Add grep pagination with `offset` and `next_offset`, reporting truncation only
  when another result exists.
- Show live busy-session markers in the resume picker and preserve its query
  and selection during synchronization.
- Show the backend's product version and license in WebUI settings and group
  provider and model configuration in one settings page.
- Refresh the model catalog, upgrade the package manager to pnpm 12 and repair
  the relocated npm smoke check for the renamed web command.
