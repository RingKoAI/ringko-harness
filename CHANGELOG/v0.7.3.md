# v0.7.3

- Rebuild the runtime around `RuntimeManager` with `CapabilityManager`,
  `ToolManager`, `ExtensionRegistry`, `AgentFactory` and `RuntimeSupervisor`.
  Plugin, skill and MCP discovery now share one revisioned capability snapshot.
- Add declarative plugins with path-bound trust, namespaced plugin skills, and
  `ringko plugins list|trust|untrust`. Project plugins can no longer inherit
  user-level trust by matching a directory name.
- Add `/skill add <directory>` with global and project installation, strict
  source validation and atomic copy.
- Create sessions from the first prompt (`seed`) instead of creating empty
  sessions when the TUI or WebUI starts.
- Scan nested `AGENTS.md` files recursively and inject them after global and
  ancestor instructions.
- Route every host through the same per-workspace backend port; `serve` reuses
  an existing CLI-started backend and multiple CLI clients can attach.
- Add tool and model lifecycle hooks, including blocking pre-execute hooks and
  diagnostic post-execute/model hooks.
- Reject one-shot schedules whose time is already in the past.
- Patch production dependency advisories through pnpm overrides and move the
  build-time `shadcn` package out of runtime dependencies.
- Keep the TUI session picker open after deleting a session, and expose
  `/skills` and `/mcp` pickers.
- Show loading, refresh and per-server connection status in the Skills and
  Connectors settings.
