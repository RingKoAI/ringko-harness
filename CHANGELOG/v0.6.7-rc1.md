# v0.6.7-rc1

- Repair an interrupted final log line under the write lock before appending, and
  resync the handle with the committed log so a torn tail cannot corrupt the
  session on the next write.
- Commit completed tool results in call order before observing cancellation, and
  record a distinct result for calls that never started.
- Include tool names and arguments in the compaction summary input, and pass the
  run signal through summarization so an aborted run records neither a
  compaction nor its prompt.
- Check the context budget before every model call in a session-backed run, so
  large tool output triggers compaction within the same turn.
