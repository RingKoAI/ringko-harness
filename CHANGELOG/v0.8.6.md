# v0.8.6

- Keep a streaming transcript pinned to its tail. The viewport is observed with
  a `ResizeObserver` instead of being re-pinned only when React state changes,
  so markdown reflow, syntax highlighting and images are followed as well.
  Opening a session from a deep link now starts at the latest message; in 0.8.5
  it landed at the top because the initial pin ran before the transcript had
  content.

- Move the jump-to-latest control from the viewport corner to the composer's
  right edge, where it stays clear of the window border and next to the input.

- Add the message quick-jump rail: one tick per message beside the message
  column, coloured by role, with the active tick tracking the reading line and
  a hover preview showing position, role and an excerpt. Clicking a tick scrolls
  to that message. The rail thins out as a conversation grows so it never
  outgrows the viewport, hides in compact layouts, and is skipped for
  conversations with a single message.
