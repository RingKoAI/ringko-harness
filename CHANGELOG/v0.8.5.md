# v0.8.5

- Rebuild the provider settings surface: searchable provider list, one-click
  preset activation cards, a full editor for endpoints, protocols, credentials
  and models, a raw JSON mode with round-trip editing, and an active/helper
  model selector on the same page.

- Add endpoint model discovery: fetch the provider's advertised model list from
  the configured base URL and key, review it in a floating picker, and add
  selected ids to the draft in one pass.

- Store multiple API keys per provider. Keys entered comma- or newline-separated
  live in `~/.ringko/auth/auth.json` and rotate round-robin with per-key usage
  tracking; the provider list reports where each credential comes from.

- Add per-model token capacity presets (128K, 200K, 256K, 1M, custom) and
  per-model `reasoningEfforts` overrides that map a thinking level to the value
  sent upstream, with validation in the config parser and the editor.

- Allow providers to be reordered by dragging their cards, with before/after
  drop indicators; the previous up/down menu actions remain for keyboard use.

- MCP connectors can be imported by pasting an `mcpServers` JSON document, and
  transport selection uses the shared select primitive.

- Replace browser-native selects across settings with the shared select
  component so themes, languages, filters and MCP transports render consistently.

- Add a usage statistics dashboard: range, scope, call-kind, provider and model
  filters, automatic refresh, pagination, and a trend chart over recorded calls.

- Composer: drag-and-drop file uploads with per-file and per-message limits,
  failed-upload reporting, and queue steering that inserts a message into the
  running turn at the next step ("steer") instead of waiting for it to finish.

- Pin favorite models in the model picker and surface provider/model
  descriptions while filtering.

- Ship the VS Code extension package: chat view, backend manager, editor
  context capture, and a webview bridge over the shared client transport.

- Host and SDK: add the preset-provider catalog endpoint, the provider model
  discovery endpoint, steering events through the session transcript, SDK
  steering helpers, and reasoning replay that keeps provider-specific blocks.

- Dependency and build updates for the WebUI (Vite 8, Tailwind 4, shadcn 4,
  React 19) plus new unit coverage for provider ordering, attachment intake,
  credential rotation, steering and preset providers.
