# v0.4.5

- Add compact, collapsible plan lists and align chat output with the composer.
- Resolve backend context limits from Models.dev with RingKo-owned local caches,
  offline snapshots, manual overrides, and separate input/context limits.
- Rename model tools to `plan` (read) and `update_plan` (replace the full list).

## Standalone downloads

Extract the archive for your operating system and architecture. Keep the `webui`
directory beside `ringko` (or `ringko.exe` on Windows). Run `ringko serve` for the
browser interface. `SHA256SUMS.txt` contains the archive checksums.

## Tool migration

Update prompts, skills, and callers that name `todoread` or `todowrite` to use
`plan` and `update_plan`, respectively. The read call takes `{}`; updates retain
the existing `{ "todos": [...] }` input. Saved permission/workflow rules are
automatically matched to the renamed tools, and recorded `session/todo` snapshots
remain readable without migration. Old names are not registered as model tools.

## Known limitation

The headless CLI and standalone embedded REPL do not yet forward catalog capacity
in this release. Their shared-capacity forwarding fix is being prepared for a
later release; it is not part of the immutable `v0.4.5` release tag.
