# v0.7.9

- Render `/status` as a command-led Settings pane opening Stats → Overview, with
  a calendar heatmap, paired activity metrics and an independent Models view.
  Add bounded, timezone-aware daily activity/streak/session-span metadata to usage
  statistics, keeping fork deduplication, range filtering and cache-inclusive totals.
- Fold tool activity by user turn in WebUI and TUI, preserving assistant replies,
  original tool order, failure visibility and per-session browser expansion choices.
- Override the workspace's node-pty build headers to node-addon-api 8.9.2;
  retain official platform prebuilds for normal installations.
- Expose per-model context windows, input/output token limits and catalog mappings
  in the visual provider editor, including OAuth model capacities. Preserve model
  metadata during discovery and respect explicit configuration files when saving.
- Use C11 for the native Node-API file module and remove its C++ runtime/toolchain
  requirement; select the source compiler with `CC`.
- Add a four-page TUI `/status` Settings panel: credential-safe Status diagnostics,
  searchable/persisted Config preferences, session Usage and workspace Stats with
  history/7-day/30-day ranges. Add `/config`, `/usage` and `/stats` shortcuts,
  bounded refresh/save operations, MCP navigation and narrow-terminal layouts.
- Add startup update checks and automatic installation preferences to Settings >
  General, with shared CLI defaults, persisted configuration and save feedback.
- Use worker-isolated Node-API file transactions for write/edit and upload commits,
  with pinned directory ancestry, no-follow checks and atomic replacement.
  Source development needs `pnpm build:native`; official npm/standalone packages
  carry matching prebuilt modules. Add native architecture and packaging checks.
- Bound edit input/output and replacement counts. Preserve literal replacement
  syntax, reject creation races and keep failed file operations from leaking locks.
- Run grep regexes in a terminable worker and enforce per-file/cumulative read,
  result and deadline budgets. Keep glob patterns/results within their approved root.
- Allowlist external CLI/ACP ambient environment; add explicit `inheritEnv` and
  command-provider deadlines. Bound stdout, stderr, frames and line sizes; safely
  launch Windows shims and reject unsupported shell interpolation.
- Stream multipart uploads with request/file/count limits, serialize workspace
  quotas, use unique names and identity-checked rollback, and drain active uploads
  on shutdown. Existing attachments are not automatically deleted.
- Bound model-rendered text separately from raw SDK results. Preserve the current
  HTTPS/SHA-256 update trust policy; no signature/attestation requirement is added.
- Restore the advertised explicit `tui` command alongside the default terminal UI.
- Place command completion candidates below the input box, retaining keyboard
  selection, Tab completion, Enter execution and Escape dismissal.
